# Example Skill

本文件是 skill 的主体：agent 只在决定使用这个 skill 后才会读到正文（渐进式披露）。
写作原则：像给一个聪明的实习生写操作手册——步骤明确、输入输出清晰、不写废话。

## 何时使用

- 触发场景 1（用户可能怎么表达）
- 触发场景 2
- 不适用场景也要写（防止误触发）

## 执行步骤

### 1. 准备

说明前置条件（依赖、环境变量、输入格式）。

### 2. 核心操作

把确定性逻辑放进 `scripts/`，SKILL.md 里只写"怎么调用脚本"：

```bash
node <skill-dir>/scripts/example.js "<输入>"
```

`<skill-dir>` 是本 SKILL.md 所在目录。

### 3. 深层参考资料

超过一屏的细节（完整目录、字段表、长示例）放到 `references/`，
在正文里用一句话指路："完整字段说明见 references/example.md"。

## 输出格式

给用户的结果长什么样，给一个最小示例。

## 注意事项

- 失败时怎么处理
- 有哪些坑
